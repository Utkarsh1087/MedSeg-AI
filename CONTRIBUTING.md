# Contributing to MedSeg-AI

Thank you for your interest in contributing to MedSeg-AI! Contributions help improve the project for everyone in the medical imaging and AI community. Please follow these guidelines to ensure a smooth collaboration process.

## How to Contribute

1. **Fork the Repository:**
   - Click the "Fork" button on the top right of the repository page [Utkarsh1087/MedSeg-AI](https://github.com/Utkarsh1087/MedSeg-AI) to create your own copy.

2. **Clone and Create a Branch:**
   - Clone your fork locally and create a descriptive branch:
     ```bash
     git checkout -b feature/model-optimization
     ```

3. **Develop & Test:**
   - Implement your changes, bug fixes, or enhancements.
   - Verify that training and prediction scripts run without errors.
   - Keep code compliant with PEP 8 standards and include documentation where appropriate.

4. **Commit Your Changes:**
   - Write clear and concise commit messages:
     ```bash
     git commit -m "Add attention mechanism to U-Net architecture"
     ```

5. **Push and Submit a Pull Request:**
   - Push changes to your fork:
     ```bash
     git push origin feature/model-optimization
     ```
   - Open a pull request against the `main` branch following the PR template.

## Code Style & Standards

- Adhere to PEP 8 Python formatting standards.
- Ensure all new public functions and classes have docstrings explaining parameters, returns, and behavior.
- Document any additional dependencies added to `requirements.txt`.

## Reporting Issues

- Use GitHub Issues to submit bug reports or propose feature requests.
- Provide step-by-step instructions and logs when reporting unexpected errors.

---

Thank you for helping push medical imaging AI forward!
