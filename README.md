**MedSeg-AI** is a robust, modular, end-to-end biomedical image segmentation pipeline engineered with TensorFlow/Keras and OpenCV. Designed for precision diagnostics and medical research, MedSeg-AI enables seamless data augmentation, custom model training, dynamic model loading, and high-throughput inference with pixel-accurate mask generation.

The framework supports execution both in local workstation environments and cloud notebooks such as Google Colab.

---

## Architecture Overview

MedSeg-AI implements an optimized U-Net encoder-decoder network with feature skip connections to preserve fine spatial details while extracting semantic context:

```
Input Image (256x256x3)
       │
       ▼
 [Conv2D 64, 3x3] ──────────────────────┐  (Skip Connection)
       │                                │
  [MaxPool 2x2]                         │
       │                                │
       ▼                                │
 [Conv2D 128, 3x3]                      │
       │                                │
       ▼                                │
[Conv2DTranspose 128, 2x2]              │
       │                                │
  [Concatenate] <───────────────────────┘
       │
       ▼
[Conv2D 1, 1x1 Sigmoid]
       │
       ▼
Segmentation Mask (256x256x1)
```

## Key Features

- **Dynamic Environment Adaptation:** Scripts and notebooks automatically detect whether they are running locally or in Google Colab, configuring paths and storage accordingly.
- **Biomedical Data Augmentation:** On-the-fly random horizontal flipping, reflection-padded rotations (-30° to +30°), and adaptive brightness scaling prevent overfitting on constrained clinical datasets.
- **Biomedical Loss & Metrics:** Utilizes **Dice Loss** and **Dice Coefficient** to handle extreme foreground-background class imbalance common in medical lesions and organ segmentation.
- **Dual Workflow Support:** Full support for both automated headless command-line interfaces (`train.py`, `predict.py`) and step-by-step interactive Jupyter Notebooks (`train.ipynb`, `Prediction.ipynb`).
- **Flexible Model Extensibility:** Plug-and-play architecture system in `segmentation_models/` allowing rapid integration and benchmarking of novel segmentation topologies.

## Data Preparation & Naming Convention

Organize your training data in the `dataset/` directory. Each image in `dataset/images/` must correspond to a ground truth mask with the **exact same filename** in `dataset/masks/`:

```
dataset/
├── images/
│   ├── scan_001.jpg
│   ├── scan_002.jpg
└── masks/
    ├── scan_001.jpg
    └── scan_002.jpg
```

## Quickstart Guide

### 1. Model Training

Train the segmentation model using the standalone CLI script:

```bash
python train.py --epochs 30 --batch_size 2 --augmentation_factor 10
```

#### CLI Parameters

| Flag | Default | Description |
|---|---|---|
| `--model_name` | `unet` | Name of model architecture in `segmentation_models/` |
| `--dataset_path` | `dataset` | Path to directory containing `images/` and `masks/` |
| `--save_model_path` | `save_trained_models` | Destination folder for trained weights and training curves |
| `--epochs` | `30` | Number of training epochs |
| `--batch_size` | `2` | Batch size for gradient updates |
| `--lr` | `0.001` | Learning rate for Adam optimizer |
| `--augmentation_factor` | `10` | Augmented samples generated per input image |

Training outputs:
- Model weights: `save_trained_models/unet_trained.h5`
- Loss curves: `save_trained_models/training_loss.png`
- Dice Coefficient curves: `save_trained_models/training_dice_coefficient.png`

### 2. Batch Inference & Prediction

Run inference over input images stored in `input_images/`:

```bash
python predict.py --threshold 0.5
```

Predictions will be binarized, resized back to each image's native resolution using nearest-neighbor interpolation, and saved into `predicted_masks/`.

## Mathematical Formulation

### Dice Coefficient

$$\text{Dice}(Y, \hat{Y}) = \frac{2 \cdot |Y \cap \hat{Y}| + \epsilon}{|Y| + |\hat{Y}| + \epsilon}$$

Where $Y$ is the ground-truth mask, $\hat{Y}$ is the predicted binary segmentation mask, and $\epsilon = 1.0$ is a smoothing term to avoid division by zero.

### Dice Loss

$$\mathcal{L}_{\text{Dice}} = 1 - \text{Dice}(Y, \hat{Y})$$
